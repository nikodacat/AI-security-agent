# v1.0 — first shippable release

**Tag:** [`v1.0`](https://github.com/nikodacat/AI-security-agent/releases/tag/v1.0) · **Date:** 2026-08-13

An AI-augmented vulnerability assessment tool that automates the reasoning a pentester does between "we detected a candidate CVE" and "here's whether it actually matters on this host."

## What v1 delivers

A three-module pipeline runnable end-to-end against any Debian/Ubuntu host or the reproducible eval-lab:

- **`host-scanner`** — package inventory, config files, services, users, port bindings
- **`cve-matcher`** — CISA KEV catalog matching + NVD version-range checking (offline)
- **`exposure-analyzer`** — Claude Agent SDK verdict loop producing per-CVE verdicts in a 5-way schema (`CONFIRMED` / `MITIGATED_BY_CONFIG` / `MITIGATED_BY_EXPOSURE` / `NOT_RUNNING` / `NO_EVIDENCE`) with non-destructive probes only

## Access-model posture

**Host-level white-box** — the tool operates with authorized privileged access on the target (Nessus/OpenVAS credentialed-scan tradition). No exploitation, no application source review, no external attacker-side probing. External validation is the missing leg — that's v2's headline feature.

See [`docs/DESIGN.md §1`](docs/DESIGN.md) for the full access-model taxonomy.

## Reproduce it

```bash
# Fresh Ubuntu/Debian server:
git clone https://github.com/nikodacat/AI-security-agent && cd AI-security-agent
./scripts/bootstrap-linux.sh

# Scan the current host:
./scripts/scan-local-host.sh --engine=claude --check-versions

# Or the reproducible eval-lab (3 vulnerable containers):
cd eval-lab && docker compose up -d --build
cd .. && ./eval-lab/run_eval.sh --engine=claude
```

## Key findings surfaced by the eval loop

1. **Analyzer reasoning was correct pre-fix; verdict *labelling* was inconsistent.** Chunk J's 14% baseline pinpointed the mismatch, chunk P's three-line SYSTEM_PROMPT edit lifted it to 100%. Full paper trail in `PROJECT_STATE.md`.
2. **cve-matcher's KEV∩dpkg substrate has a real coverage gap** — source-built binaries (httpd 2.4.49) and non-dpkg artifacts (log4j jar) are invisible. Documented as v2 aspirational GT.
3. **`safe=True` was over-claimed pre-chunk-V.** Post-construction mutation trivially bypassed the invariant. Fixed with `@dataclass(frozen=True)` + test.

## What's next (v2)

Work happens on the `v2-dev` branch. Targeted modules:

- **`network-prober`** — external service verification (nmap-style). Unlocks the full gray-box label.
- **Dynamic probe generation** (allow-list + HITL). Structured argv from Claude, operator approval before execution.
- **`attack-simulator`** (PentestGPT bridge). Advisory attack-path planning; no live exploitation.
- **`fix-publisher`** — advisory remediation drafts (may punt to v3).

Full v2 sketch in `docs/DESIGN.md §1.3`.
